Engineering highlights

Four decisions worth explaining.

%

Explainable matching

Fixed weights — urgency 40, distance 30, capacity 20, food fit 10 — with a reason string, unit-tested.

◉

Live tracking

Server-Sent Events stream location from Spring through the Next.js proxy; a strict state machine allows only valid pickup transitions.

{ }

Full-stack

Next.js 16 + TypeScript + Tailwind v4 on the front; Spring Boot 4.1 (Java 21) + Spring Data JPA + Flyway on the back; Postgres on Supabase.

✓

Auth, two ways

Donors sign in with phone OTP (Phone.email); volunteers, NGOs and admins with JWT (HS256) + BCrypt — role-checked on every request.
